# RimMT V0.4.17.1 Playtest Notes

## Purpose

V0.4.17.1 is a compatibility hotfix for the first real V0.4.17 `parallel.workPrefilter` playtest on the target large mod list.

The V0.4.17 runtime correctly failed closed because all three authoritative WorkGiver targets had foreign Harmony owners:

- GrowerSow: `rimworld.biomes.core :: BiomesCore.Patches.Plants.WorkGiver_GrowerSow_JobOnCell_Patch.Prefix`
- GrowerHarvest: `rimworld.erdelf.alien_race.main :: AlienRace.HarmonyPatches.HasJobOnCellHarvestPostfix`
- BuildRoof: `Dartstriker.Watchtowers :: Watchtower.HarmonyPatches.Patch_WorkGiver_BuildRoof+HasJobOnCell.Postfix`

As a result, V0.4.17 reported `kindCompat(sow/harvest/roof)=False/False/False` and produced zero Work-prefilter worker cells. V0.4.17.1 source-reviews the first two cases rather than weakening the global compatibility guard.

## Exact coexistence policy

### GrowerHarvest + Humanoid Alien Races

The reviewed AlienRace Postfix exits immediately when Vanilla/RimMT already returned false. When the incoming result is true, it applies a race restriction and may turn the result false. It therefore acts only as downstream true-to-false authority.

V0.4.17.1 re-enables harvest prefiltering only when the exact owner, declaring type, method name and patch kind match this reviewed Postfix and no additional unknown foreign patch owns the target.

### GrowerSow + Biomes! Core

The reviewed Biomes Prefix installs wanted-plant context so `PlantUtility.GrowthSeasonNow` can use plant-specific season semantics. That context is shared/static and must not be reproduced from worker threads.

V0.4.17.1 re-enables Sow in **restricted mode** only for the exact reviewed Biomes Prefix. The existing worker may still publish other hard negatives, but whenever the selected prediction reason contains `OutOfGrowthSeason`, the compatibility shim forces `TryFastNegative` to return false so the main-thread Vanilla `JobOnCell` executes normally with Biomes' own context.

If the shim cannot inspect the private prediction state, it also falls back to Vanilla for that Sow call.

### BuildRoof + Watchtowers

No source-reviewed semantics were available for the current Watchtowers Postfix. BuildRoof therefore remains fail-closed in V0.4.17.1.

## Safety invariants retained

- Main thread never waits/spins for Work-prefilter workers.
- Workers never create Jobs.
- Workers never reserve targets.
- Workers never commit Pawn/Thing/Map state.
- Unknown/positive candidates remain Vanilla.
- Sampled negative parity remains Vanilla-authoritative.
- False-negative parity mismatch still cools the slot and contributes to the global fuse.
- Any additional unknown Harmony patch on the reviewed WorkGiver target keeps that Work kind fail-closed.

## Expected target-save runtime after loading

The desired compatibility outcome is:

- GrowerSow: enabled through `biomesSowRestricted=True`
- GrowerHarvest: enabled through `alienHarvest=True`
- BuildRoof: disabled while Watchtowers remains unreviewed

The V0.4.17 core compatibility line may print its original fail-closed decision before the V0.4.17.1 postfix adjusts the reviewed cases. The authoritative evidence for this hotfix is the subsequent V0.4.17.1 coexistence log and later Work-prefilter metrics.
