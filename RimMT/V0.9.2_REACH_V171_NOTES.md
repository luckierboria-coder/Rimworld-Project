# V0.9.2 Unified Lean — Reach V17.1

Based on the exact SlicedReach V17 build at `8ec566d64685cf3619ddff798dc018f32b7701b1`.

## Changes

- Apply a shared per-frame admission budget to main-thread Region.Allows profile captures, using the existing adaptive 0.5–2 ms budget. A capture already admitted completes atomically; this is not a hard real-time limit and does not reduce the cost of an individual Region.Allows call.
- Resume topology adjacency traversal inside a region, deduplicate edges with a HashSet while preserving first-seen order, check slice budgets more frequently, and check flattening progress even for isolated regions with no edges.
- Validate a reachable Touch/ClosestTouch candidate cell with the live ReachabilityImmediate endpoint predicate. If that coarse candidate is not a legal endpoint, fall back to Vanilla rather than claiming unreachable. Target areas above 256 cells also fall back.
- Return Unknown/Vanilla if no start region can be established or the fixed root-component buffer overflows; never silently drop components and infer unreachable.
- Keep warmup/sample counters on the exact immutable profile snapshot's validation state, rather than on the reusable slot. Ignore comparisons against a profile replaced during the original call.
- Report all DoBill fabric admission exits separately: threshold, invalid query, defined ThingRequest, region policy, unknown collection, too few candidates and too many candidates. Eligibility and worker limits are unchanged.

## Limits

The prior report's 18 mismatches cannot be reproduced from aggregate counters alone. These changes address specific code-level edge cases; they do not establish that all 18 had the same cause or promise zero mismatches under 392 mods.

The general persistent fabric recorded 292 eligible calls and 292 mobile-source bypasses. Its static-source contract is retained. The DoBill report did not distinguish its early exit reasons, so thresholds are not lowered speculatively.

Compare the same save and scene after a fresh game launch. Watch `parityMismatches`, `touchEndpointRejected`, `captureBudgetBypasses`, `maxCaptureFrameUs`, `maxTopologySliceUs`, and `admissionBypass`. Real-game correctness and frame-time benefit require playtesting; a successful build is not a gameplay benchmark.
